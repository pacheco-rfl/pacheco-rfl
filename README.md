## 🚀 Projeto em Destaque — Centraliza

O **Centraliza** é uma plataforma Full Stack para gestão centralizada de processos operacionais.

O projeto é composto por três aplicações independentes: **React + TypeScript + Vite** no frontend, **Java + Spring Boot + PostgreSQL** no backend e **Python + Selenium** para automação.

A aplicação possui autenticação **JWT**, controle de acesso **RBAC**, usuários, cargos e permissões específicas, auditoria, processamento de documentos, migrations com Flyway e documentação da API com Swagger.

Um dos principais diferenciais é a integração entre **Java e Python**, na qual a API inicia processos de automação através de `ProcessBuilder` e acompanha o progresso das execuções.

O projeto também possui testes automatizados no backend, cobertura com JaCoCo e pipelines independentes de integração contínua com GitHub Actions.

🔗 **Conheça o projeto completo:**  
https://github.com/pacheco-rfl/centraliza
